项目概述

面向职业卫生人员的 AI 辅助识别 Agent：从 MSDS 成分章节提取 CAS 编号、含量和页码证据，匹配职业病危害因素知识表，对不确定项交回人工复核。V1 用 PDF 文本抽取仅达 8/12，V2 引入本地中文 OCR + 页图证据链后提升至 11/12，剩余 1 例保留为 Bad Case 不强行修对。

面临的挑战

MSDS 文件格式多样（文本型 PDF + 扫描件），物质识别准确性直接关系职业病危害判定——既要降低人工成本，又不能在关键判定上出错或伪造字段。

用户研究与洞察

1

梳理职业卫生审核流程，明确物质名称、CAS 编号、含量三类核心提取字段

2

对照《高毒物品目录》与内部知识表，理清判定逻辑与安全边界

3

用 3 份真实 MSDS 人工标注构建黄金集，V1 评测仅 8/12，定位扫描件文本丢失为主要瓶颈

解决方案

1

V1：PDF 文本抽取 + CAS 校验，覆盖文本型 PDF，但扫描件成分章节无法提取

2

V2：增加本地 Tesseract 中文 OCR + 页图截图，每条提取结果附页码证据，可点击溯源

3

CAS 规范化与校验：保留原始 CAS 与规范 CAS，未命中标记「知识表未命中」而非「无危害」

4

三级输出：自动通过 / 人工确认 / 必须复核，高毒目录命中强制人工复核

工作流

5 步证据链工作流

每一步职责单一、独立校验，避免单点错误传导到最终判定。

步骤做什么异常处理
1. 章节定位解析 PDF，定位「成分/组成信息」章节章节缺失 → 转人工
2. 文本 / OCR文本型走 PDF 抽取；扫描件走本地 Tesseract 中文 OCROCR 字段缺失 → 降置信度，不伪造
3. CAS 校验CAS 编号规范化 + 校验位验证，保留原始值与规范值格式异常 → 标记，转人工确认
4. 知识表匹配CAS 精确匹配 + 名称模糊匹配职业病危害因素库未命中 → 「知识表未命中」≠ 无危害
5. 分级输出自动通过 / 人工确认 / 必须复核，附页码证据高毒目录命中 → 必须人工复核
产品设计

三条安全规则：AI 辅助判定，不替代专业判断

职业病危害判定错误代价高，产品设计的核心不是「全自动」，而是「知道什么时候该停下来」。

规则怎么做为什么
不伪造字段OCR 缺失、编码异常时降置信度并标记，绝不填充猜测值伪造的 CAS 会导致错误的危害判定，比漏检更危险
高毒必复核命中《高毒物品目录》的物质强制人工复核，不允许自动通过高毒物质的漏判后果不可逆
未命中 ≠ 无危害CAS 未命中知识表时输出「当前知识表未命中」，而非「无危害」知识表覆盖有限，未命中只代表不在表中，不代表安全
产品思考

为什么保留 Bad Case：Sn 被 OCR 识别成 Sm

V2 剩余 1 例失败没有「修成正确」，而是公开保留——这比一个完美的准确率数字更有说服力。

扫描件中锡（Sn）的化学式被 Tesseract OCR 误识别为钐（Sm），导致 CAS 匹配到错误物质。我没有通过后处理规则强行修正，而是把它保留为 Bad Case，原因有三：

1. 修一个 Bad Case 容易，但修的规则可能在其他样本上引入新错误——小样本下尤其危险；

2. 评测样本只有 3 份真实 MSDS，样本量小，不宣称通用准确率，保留失败比掩盖失败更诚实；

3. 这个 Bad Case 本身就是产品边界的说明：扫描件 OCR 误差是当前方案的已知局限，后续应通过更高质量 OCR 引擎或人工复核环节解决。

对 B 端合规工具来说，用户信任的不是 100% 的数字，而是「你知道自己哪里会错」。

成果与影响

完成从 V1 到 V2 的迭代：PDF 文本抽取 → 本地 OCR + 证据链，黄金集 8/12 → 11/12；设计三条安全规则（不伪造字段、高毒必复核、未命中≠无危害），每条判定保留原始 CAS、规范 CAS、页码与处理动作。

复盘与反思

B 端合规场景里，「可溯源」和「知道自己不知道」比「看起来准」更重要。AI 应该先保证不犯错、不伪造，再谈提效；保留 Bad Case 比掩盖它更有说服力。
